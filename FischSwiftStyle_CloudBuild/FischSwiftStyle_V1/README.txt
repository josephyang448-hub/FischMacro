Fisch Macro — Swift-style V1

Run from source:
  py -m pip install -r requirements.txt
  py main.py

Build EXE:
  Double-click build_exe.bat
  Output: dist\FischSwiftStyle.exe

This is a screen-based prototype. It reports generic visual candidates for fish/marker positions.
It does not access or modify Roblox memory, inject code, or bypass game protections. It does not
send automatic mouse/keyboard inputs yet: visual detection must be calibrated first, otherwise
it could click unpredictably. Use the live coordinates and adjust the screen region settings.
